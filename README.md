# Nassau Candy Project

# Product Line Profitability & Margin Performance Analysis

## Project Overview

This project analyzes product-level profitability, gross margin performance, and division efficiency for Nassau Candy Distributor using data analytics and interactive visualization techniques.

The objective is to identify:
- High-profit products
- Low-margin products
- Revenue-profit imbalance
- Cost-heavy products
- Profit concentration risks

---

## Problem Statement

The organization lacks visibility into:
- Which product lines deliver the highest gross margins
- Whether high-sales products are actually profitable
- How profitability varies across divisions
- Which products represent margin risk

This project transforms raw sales and operational data into actionable business insights.

---

## Business Insights

- Certain chocolate products contribute the majority of company profit.
- Some high-sales products operate with low margins.
- Profitability is concentrated among a small number of products.
- Cost-heavy products reduce operational efficiency.

---

## Recommendations

- Focus marketing on high-margin products
- Re-evaluate pricing strategies
- Optimize manufacturing costs
- Reduce dependency on limited products
- Monitor profitability using dashboards

This project demonstrates how data analytics and interactive dashboards can improve profitability analysis, operational visibility, and strategic business decision-making.
